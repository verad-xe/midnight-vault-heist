Midnight Vault is a one-screen top-down stealth heist game: cross the museum gallery past patrolling guards and sweeping security cameras, crack the vault, steal the Star Sapphire, and slip out the exit before the alarm meter hits 100. Several routes cross each room — the open gallery, a camera-only side corridor, and the slow vent shafts where no cone can see you — and smoke pellets and noisemaker coins trade score and alarm for room to move.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or the arrow keys (or click the floor), hold Shift to sneak, press E to grab loot and pick the vault lock, 1 for a smoke pellet, 2 for a noisemaker coin, R to restart.
